\begin{frame}{S1: señales y problemas que condicionan el modelo}
\framesubtitle{El análisis exploratorio se convierte en decisiones técnicas}

\metric{Faltantes}{48,0 \%}{Sunshine; Evaporation 43,2 \%}
\column{0.24\textwidth}
\metric{Colinealidad}{$r \approx 0{,}985$}{MaxTemp--Temp3pm}
\column{0.24\textwidth}
\metric{Rainfall}{Cero-inflada}{Cola derecha extrema}
\end{columns}
\vspace{0.15cm}
\begin{columns}[T,onlytextwidth]
\column{0.49\textwidth}
\begin{block}{Señales relevantes}
\begin{itemize}
\item Humidity3pm: asociación positiva más fuerte.
\item RainToday y Rainfall: persistencia de precipitación.
\item Pressure9am: asociación protectora.
\item WindGustSpeed: señal útil, sensible a extremos.
\end{itemize}
\end{block}
\column{0.49\textwidth}
\begin{block}{Consecuencias para S3}
\begin{itemize}
\item Imputar en vez de borrar casos completos.
\item No usar MaxTemp y Temp3pm simultáneamente.
\item Aplicar \texttt{log1p} a Rainfall.
\item Usar métricas sensibles a la clase minoritaria.
\end{itemize}
\end{block}
\end{columns}

\begin{frame}{S2: validación y retroalimentación}
\framesubtitle{La evidencia validada define la arquitectura del modelo final}
\begin{columns}[T,onlytextwidth]
\column{0.48\textwidth}
\begin{block}{Validado en S2}
\begin{itemize}
\item Correlaciones estables: Humidity3pm, RainToday, Humidity9am, Pressure9am y Rainfall.
\item Permutación con estadístico studentizado y $p<0{,}001$.
\item Bootstrap coherente con intervalos clásicos.
\item Rainfall requiere lectura robusta y \texttt{log1p}.
\end{itemize}
\end{block}
\column{0.48\textwidth}
\begin{block}{Retroalimentación incorporada}
\begin{itemize}
\item Notebook ejecutable de principio a fin.
\item Cada cifra sale de la misma corrida.
\item Ponderación de clase y métricas minoritarias.
\item Partición temporal o agrupada por Location.
\end{itemize}
\end{block}
\end{columns}

\begin{frame}{S3: reproducibilidad y ausencia de fuga}
\framesubtitle{Preparación aprendida solo desde el entrenamiento temporal}
\begin{columns}[T,onlytextwidth]
\column{0.48\textwidth}
\begin{block}{Flujo reproducible}
\begin{enumerate}
\item Cargar datos y excluir \texttt{RISK\_MM}.
\item Ordenar por fecha.
\item Separar 70 \% entrenamiento y 30 \% prueba.
\item Aprender imputación, escalamiento y selección.
\item Evaluar en prueba temporal intacta.
\end{enumerate}
\end{block}
\column{0.48\textwidth}
\begin{block}{Qué se aprende solo con entrenamiento}
\begin{itemize}
\item Modelos de imputación.
\item Medianas y modas.
\item Parámetros de estandarización.
\item Límites de winsorización.
\item Selección de variables.
\end{itemize}
\end{block}
\end{columns}
\begin{block}{Resultado}
El desempeño reportado se mide sobre datos cronológicamente posteriores, no sobre una mezcla aleatoria.
\end{block}
\end{frame}
